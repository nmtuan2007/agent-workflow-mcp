# Prompt Catalog

- `brainstorm_feature`: turn an idea into a concrete brief.
- `write_engineering_spec`: draft a structured engineering spec.
- `generate_task_plan`: break an approved spec into executable tasks.
- `request_code_review`: request review against plan and quality criteria.
- `verify_done`: assess whether evidence is sufficient.
- `summarize_workflow_state`: summarize state, artifacts, blockers, and next action.
